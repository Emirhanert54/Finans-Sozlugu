# Etkileşimli Finans Sözlüğü (Web Uygulaması)

[![Canlı Demo](https://img.shields.io/badge/Canlı_Demo-Yayında-success?style=for-the-badge&logo=netlify)](https://interaktif-finans-sozlugu.netlify.app)

Kullanıcıların temel finans, ekonomi ve borsa terimlerini kolayca öğrenebilmesi için tasarlanmış, hızlı ve modern bir web tabanlı sözlük uygulamasıdır. Herhangi bir ağır framework kullanılmadan tamamen saf (Vanilla) dillerle kodlanmış olup, tüm cihazlarda kusursuz çalışacak şekilde (Responsive) optimize edilmiştir.

## Canlı Sürüm
Projeyi tarayıcı üzerinden canlı olarak incelemek için tıklayın: **[Finans Sözlüğü Canlı Demo](https://interaktif-finans-sozlugu.netlify.app)**

## Teknolojiler (Tech Stack)
- **Markup & Stil:** HTML5, CSS3
- **Dinamik Mantık (Logic):** Vanilla JavaScript (ES6+)
- **Deployment & Hosting:** Netlify

## Öne Çıkan Özellikler
- **Anlık Arama Algoritması:** JavaScript ile terimler arasında gecikmesiz, anında (real-time) filtreleme.
- **Tam Mobil Uyumluluk:** CSS Flexbox/Grid mimarisiyle telefon, tablet ve masaüstü ekranlara duyarlı (Responsive) tasarım.
- **Yüksek Performans:** Harici bir kütüphane (React, Vue vb.) yükü olmadan, doğrudan tarayıcı üzerinde en hızlı render süresi.

## Kurulum ve Çalıştırma
Projeyi kendi yerel ortamınızda (localhost) çalıştırmak için ekstra bir sunucu veya paket kurulumuna ihtiyaç yoktur:
1. Repoyu bilgisayarınıza indirin (`git clone`).
2. Klasör içindeki `index.html` dosyasını herhangi bir web tarayıcısında (Chrome, Safari vb.) açmanız yeterlidir.
